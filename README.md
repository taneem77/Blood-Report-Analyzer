# 🩸 Blood Report Analyzer

## 📘 Overview
**Blood Report Analyzer** is a Python project that reads and interprets blood test data from a CSV file. It compares each value to medical reference ranges, classifies results as *Low*, *Normal*, or *High*, and offers brief health tips. Designed as an **educational tool**, it demonstrates file handling, data validation, and conditional logic in Python.

---

## ⚙️ Features
- 📄 Reads and validates CSV input (`Blood Report Details(CSV).csv`)  
- ⚖️ Compares test values to reference ranges  
- 🧠 Classifies readings as Low, Normal, or High  
- 💡 Displays personalized tips for abnormal values  
- 🧾 Auto-generates a sample CSV if missing  

---

## 🧩 Technologies
- **Language:** Python 3  
- **Libraries:** `csv`, `os`  
- **Input:** Two-column CSV → `Test Name, Value`

---

## 🧬 Example Output
Hemoglobin: ✅ Normal
HDL Cholesterol: 🔻 Low – Exercise and eat healthy fats
Uric Acid: 🔺 High – Avoid red meat and sugary drinks
